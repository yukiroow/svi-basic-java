# Basic Java Exercises

This repository contains the practice exercises in the Basic Java Training Curriculum

## v1.0

This version contains the Practice Exercise indicated in the `Day 1 - Session 3` section.

### Specifications

- Simple create user object with 
- Use 1 java main class
- Create the necessary variables to hold the ff:
  - First Name
  - Last Name
  - Username
  - Password
- Create a console menu that displays the ff sub menus
  - Create an Account
  - Update an Account
  - Display Account
  - Exit
- Allow the user to select any of the options via the console
- Behavior of the 3 selections when selected
  - Create an Account
    - Prompt to enter the fields mentioned above
    - After entering all fields, save the data to the object and redisplay the main menu again
  - Update an Account
    - Prompt which Account attribute to be updated (except for username)
    - Save the new data
    - Redisplay the main menu again
  - Display Account
    - Displays the labels and values of the attributes
    - Displays the main menu again
  - Exit
    - Exit the program
